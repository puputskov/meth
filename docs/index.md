matlog is an interactive math shell. You write notes and math lines in a
session, and every math line shows its result as you type. The pages below
are the same in the tool (`:help`) and on the command line (`matlog docs`).

# Using the tool
- [The tutorial](tutorial): learn the tool by doing, in small lessons.
- [The editor and its keys](editor): typing, moving, selecting, blocks,
  folds, undo.
- [Commands](commands): everything you can type after {ACTION_COMMAND}.
- [Themes](themes): colours and your own theme files.
- [Settings](settings): the settings file and what you can change.
- [Key bindings](keys): the actions of the editor and their keys.
- [Export](export): a session as LaTeX, MathML or Markdown.
- [Examples](examples): worked problems, from fractions to a robot arm.
- [Snippets](snippets): small pieces of a session to put in and change.
- [The documentation](docs): how this help works, and searching it.

# The math
- [The algebra syntax](syntax): numbers, operators, names and statements.
- [Functions](functions): the built in functions and constants.
- [Statistics](statistics): means, spread, correlation, fits, distributions.
- [Plots](plots): histograms, scatter plots and lines in the side panel.
- [Complex numbers and quaternions](complex): i, j, k, the Hamilton product, rotations.
- [Matrices and vectors](matrices): matrices, determinants, inverses.
- [Symbolic math](symbolic): simplify, expand, differentiate, integrate,
  limits, equations.
- [Units](units): quantities, conversions, prefixes.
- [Boolean algebra](boolean): expressions, truth tables, simplification.
- [Lambda calculus](lambda): terms, reduction, Church numerals.

# Files and scripts
