matlog is an interactive math shell. You write notes and math lines in a
session, and every math line shows its result as you type. The pages below
are the same in the tool (`:help`) and on the command line (`matlog docs`).

# Using the tool
- [The editor and its keys](editor): typing, moving, selecting, blocks,
  folds, undo.
- [Commands](commands): everything you can type after Ctrl+P.
- [Themes and settings](themes): colours, the settings file, your own
  theme files.
- [Export](export): a session as LaTeX, MathML or Markdown.
- [The documentation](docs): how this help works, and searching it.

# The math
- [The algebra syntax](syntax): numbers, operators, names and statements.
- [Functions](functions): the built in functions and constants.
- [Matrices and vectors](matrices): matrices, determinants, inverses.
- [Symbolic math](symbolic): simplify, expand, differentiate, integrate,
  limits, equations.
- [Units](units): quantities, conversions, prefixes.

# Files and scripts
- [The session file](fileformat): the `.mlog` format.
- [The command line](cli): evaluate, run, export and read the docs from
  scripts.
